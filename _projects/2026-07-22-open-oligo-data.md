## Background

Public data relevant to therapeutic oligonucleotides, especially experimental data like potency, stability and safety — is scattered across many disconnected sources. Bringing it together in one open, well-described resource would make it far more useful to researchers and form the basis for future improvements.

## What you'll do

- Identify the relevant public data sources for potential therapeutic oligos
- Build pipelines to collect, parse, and organise the data
- Describe the data with consistent, reusable metadata
- Expose the result via an open database or API for others to build on

## Requirements

Interest in data engineering and/or bioinformatics, and comfort with scripting (Python or R). An interest in RNA/oligonucleotide biology is a plus.
