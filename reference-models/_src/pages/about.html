What this site is

An onboarding guide and reference for CPDSE-teachers. The [[page:./|Start page]] explains why CPDSE works from three reference models and how they fit together. The explorers for [[model:where|Where]], [[model:what|What]] and [[model:how|How]] let you look up every substep, competency and practice, and follow the links between them.

The site is not yet linked from the main cpdse.dk navigation and asks search engines not to index it.

Status of the content

The Pharma Value Chain ($vc_version) and the Pedagogic Practices ($ped_version) are marked in their source documents as AI-drafted and pending review, so every page for those two models carries a draft badge. The PDS Competence Model has no version number; this site shows the date it last changed ($competence_date).

The connections between the value chain and the competence model come only from the tool crosswalk ($n_crosswalk links). CPDSE deliberately does not keep a fixed map from substeps to competencies: targets are set for each course or workshop.

The two worked examples use real courses. The People Development workshop, the starting levels, the targets and the session designs are illustrative.

How it is built

Every page is generated by a script in the website repository from the CPDSE reference-models repository at commit $source_sha ($source_date). Page copy like this is written by hand; model content is read from the source documents and vocabulary files, so the site changes when the models change and the site is rebuilt.
