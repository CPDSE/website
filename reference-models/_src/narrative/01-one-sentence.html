Training from the Back of the Room is a teaching approach by Sharon Bowman in which participants, not the teacher, do most of the work.)

Why three models, not one

Every course or workshop has to answer where, what and how. One model that tried to cover all three would become vague, so each question has its own model. Each model is also self-contained, so it can change without breaking the others.

For every course or workshop we help design, we combine them in the same order: anchor it in the value chain, assess current levels and set targets, then deliver the teaching. That shared order keeps CPDSE's work consistent across teachers, courses and partners. Curriculum courses and People Development workshops use the same three models; only the balance between them differs.

Key idea: one model per question, combined in the same order every time.
